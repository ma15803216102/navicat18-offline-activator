## 一、它到底做了什么

Navicat 的「手动激活」是一个很标准的模型：

```
客户端用内置公钥 加密 机器信息  →  请求码
厂商用私钥 解密请求码、构造许可、再用私钥签名  →  激活码
客户端用内置模数 验证激活码，通过后写入许可
```

难点就在最后一步：**验证用的模数是厂商的**，你的签名它当然不认。

那怎么办？把这把钥匙也换掉。

| 位置 | 原本 | 换成 |
|---|---|---|
| `navicat.exe` 里的请求码公钥 | 厂商 RSA-2048 公钥（明文 PEM） | 你生成的公钥（同长度 460 字节覆盖） |
| `libcf.dll` 里的验签模数 | 厂商模数（运行时才构造出来） | 你的模数（`.pmod` 跳板 / 运行时 shell） |

换完之后，Navicat 自己的 RSA 校验会**用你的模数**去验**你用自己私钥签出的激活码**——天然通过。

## 二、三个我认为值得说说的设计

### 1. 离线：私钥在你手里，不在服务器

很多同类工具要联网、要卡密、要"登录授权"。我这版直接把签发私钥编译进了 exe（OTP 密文形式）。

好处是：**断网能用、没有服务器、不会被跑路。**
代价是：**任何拿到这个 exe 的人都能给自己签发激活码。**

所以我在 README 里写得很直白：自己构建的 exe 不要外发；要给别人用，让对方自己 clone 源码、生成自己的密钥对。

### 2. 两种补丁方式，各有取舍

| | `libcf.dll`（文件级） | 内存补丁（运行时） |
|---|---|---|
| 改不改 Navicat 文件 | 改（`libcf.dll` + `navicat.exe`） | **不改** |
| 持久性 | **持久**，重启有效 | 不持久，每次重启要重打 |
| 官方更新后 | 被覆盖，要重装 | 不受影响 |
| 杀软观感 | 通常不报 | 跨进程改内存，可能误报 |

文件级补丁的做法是给 `libcf.dll` **新增一个可执行节 `.pmod`**（352 字节 shell），然后把目标函数前 21 字节改成 `E9 rel32` + 16 个 `NOP` 跳过去：

```
shell 保存现场
  → 把调用现场对象里的验签模数换成你的
  → 执行原序言
  → jmp 回 入口+21
```

内存补丁则更干净：直接 `OpenProcess` + `WriteProcessMemory`，**不生成、不修改任何文件**。

### 3. 不落盘

早期版本会往 Navicat 目录放一个 `version.dll` 代理。问题来了：**Windows 不允许删除已被进程映射的 DLL**（`DeleteFile` 直接拒绝访问），只能改名成 `~nvp_xxx.tmp` 等重启后删。

后来改成了内存补丁，这条路就彻底不需要了——Navicat 在运行时直接改内存，**目录里干干净净**。

## 三、怎么用（6 步）

> 前置：Windows 10/11 x64、.NET Framework 4.x、Python 3（构建时用）

**① 构建**（本仓库不附带成品 exe）

```bat
python tools\gen_keys.py        rem 生成你自己的密钥对
python tools\gen_payload.py     rem 把 shell 里的模数换成你的
python tools\gen_offline.py     rem 用私钥生成签发代码
build\build_offline.cmd         rem 编译
```

**② 以管理员身份运行**，选补丁方式，点【安装补丁】

**③ 手动双击打开 Navicat**（必须是你自己开的，工具启动的会失败）

**④ 在 Navicat 里点【帮助 → 注册】**

![帮助菜单](images/navicat-help-menu.png)

![注册窗口](images/navicat-register.png)

**⑤ 回到工具点【开始激活】**，剩下的它自己跑完：
读请求码 → 本机签发 → 填激活码 → 按 Ctrl+Shift 点激活 → 进手动激活窗口 → 完成。

## 四、几个真踩过的坑（也是给同行的提醒）

**① 内存补丁不持久**
Navicat 每次重启后要重新点一次【安装补丁】。如果你发现"明明激活过又变回未激活"，八成是这个原因。

**② 两种方式互斥**
文件级补丁会把函数入口改成跳板；此时再装运行时补丁，必然报「在 libcf.dll 的可执行节里没找到函数序言」——
这不是 bug。**要切方式，先卸载。**

**③ 卸载会删掉 `.orig` 备份**
工具卸载时会把 `.orig` 拷回原位然后删掉备份。想保留退路，装补丁前自己另外复制一份 `navicat.exe` / `libcf.dll`。

**④ 杀软误报**
改 DLL、跨进程写内存——这在启发式引擎眼里就是可疑行为。加排除目录或临时关闭实时防护即可。

**⑤ 版本相关**
目标函数的 21 字节序言是版本相关的。换 Navicat 大版本需要重新定位特征字节（改 `src/pdata.cs` 里的 `_pro`）。
