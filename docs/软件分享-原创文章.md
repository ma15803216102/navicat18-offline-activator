# 我给 Navicat 18 写了个离线激活工具

正版买不起，就自己写了个。不联网、不用服务器、不用卡密，源码开源。

## 原理

Navicat 的手动激活是 RSA 签名那一套：请求码用内置公钥加密，你拿回来的激活码用内置模数验签。

问题在于验签用的是厂商的模数，我签的东西它不认。

所以我把这两把钥匙都换了：

- `navicat.exe` 里的请求码公钥是明文 PEM，同长度覆盖成我的；
- `libcf.dll` 的验签模数不在文件里，只能运行时给目标函数装跳板——新加一个 `.pmod` 节，把函数前 21 字节改成 `E9` 跳过去，在跳板里把模数换成我的，再跳回来。

换完，它验的就是我自己签的激活码。

## 两种补丁方式

| | libcf.dll | 内存补丁 |
|---|---|---|
| 改文件 | 改 `libcf.dll` 和 `navicat.exe` | 不改 |
| 持久性 | 重启有效 | 每次重启 Navicat 要重打 |
| 官方更新 | 被覆盖，要重装 | 不受影响 |

内存补丁是直接 `OpenProcess` + `WriteProcessMemory`，不落任何文件。之前那版会释放一个 `version.dll` 代理，但 Windows 不允许删除已映射的 DLL，只能改名留个 `~nvp_*.tmp` 尾巴，所以后来改成纯内存。

**两种方式互斥**：文件级补丁占了函数入口，再装运行时补丁会报「没找到函数序言」。切换之前先卸载。

## 怎么用

先构建（仓库不附带成品 exe）：

```bat
python tools\gen_keys.py
python tools\gen_payload.py
python tools\gen_offline.py
build\build_offline.cmd
```

然后：

1. 管理员运行，选补丁方式，点安装补丁；
2. 自己双击打开 Navicat——工具启动的不行；
3. Navicat 里点 帮助 → 注册；
4. 回工具点开始激活，剩下的它自己跑完。

## 踩过的几个坑

1. 内存补丁不持久，重启 Navicat 要重打一次。看到「激活过又变未激活」基本是这个原因。
2. 两种方式互斥，切换前先卸载。
3. 卸载会把 `.orig` 备份拷回去删掉。想留退路，装补丁前自己复制一份 `navicat.exe` 和 `libcf.dll`。
4. 杀软会误报——改 DLL、跨进程写内存，行为上确实像。
5. 目标函数的 21 字节序言是版本相关的，换 Navicat 大版本得重新定位（`src/pdata.cs` 的 `_pro`）。
